# CamDiv - Free Random Video Chat Platform

[![Website](https://img.shields.io/website?url=https%3A%2F%2Fcamdiv.com&label=camdiv.com)](https://camdiv.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**[CamDiv](https://camdiv.com)** is a moderated random video, voice and text chat platform for adults aged 18 and over. Guests can complete the age and gender prompts without a social login. Match availability and connection times vary. CamDiv uses encrypted WebRTC for video and voice; moderation reduces some risks but cannot guarantee a safe interaction.

The official platform is **camdiv.com**, operated by **CAMDIV PRIVATE LIMITED** (CIN **U62099KL2026PTC106632**). Other domains using the CamDiv name are not affiliated with this service. See [About CamDiv](https://camdiv.com/about) for company and product information.

## ✨ Features

- **Guest access**: Adults can continue after the guest prompts. Optional sign-in provides account features; account details are not displayed to chat partners.
- **Random matching**: Separate queues match available users in each mode. Waiting times vary; a particular person, country or language is not guaranteed.
- **Multimodal Chat**: 
  - 📹 **Video Chat**: Face-to-face conversations; quality depends on devices and connections.
  - 🎙️ **Voice Chat**: Audio-only mode for privacy.
  - 💬 **Text Chat**: Real-time messaging.
- **Web and Android**: Supported current desktop and mobile browsers, plus an optional [Android app](https://play.google.com/store/apps/details?id=com.camdiv). Device support and availability vary.
- **Safety tools**: Automated sampled-frame checks can hide or blur video. User reporting and human review support separate enforcement. See the [Community Guidelines](https://camdiv.com/community-guidelines).
- **Free core chat and optional VIP**: Core video, voice and text chat are free. Eligible VIP members receive the benefits and subtitle allowances shown on the current [pricing page](https://camdiv.com/pricing). Subscriptions renew automatically until cancelled.
- **Live translated subtitles**: Available to eligible accounts in video and voice chat, subject to supported languages, usage allowances and service availability. Speech recognition and translation may be inaccurate or delayed; review the [Privacy Policy](https://camdiv.com/privacy) for data processing.

## 🛠️ Technology Stack

CamDiv is built with a focus on performance and privacy:

- **Frontend**: [Next.js](https://nextjs.org/) (React)
- **Real-time Communication**: [WebRTC](https://webrtc.org/) (Peer-to-Peer)
- **Styling**: Tailwind CSS
- **Infrastructure**: DigitalOcean application hosting and CamDiv-operated TURN relays when a direct media connection is unavailable.
